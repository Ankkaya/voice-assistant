# 儿童首页与家长设置优化设计

日期：2026-08-02  
状态：已确认，待实施  
目标平台：Flutter Android

## 1. 目标

将当前混合了儿童通话、音色实验和角色管理的首页拆分为两个职责清晰的入口：儿童首页只用于邀请角色来电；家长设置用于配置所有角色的音色并管理自定义角色。

成功标准：

- 儿童无需理解“预置音色、音色设计、音色克隆”等技术概念即可发起流程。
- 所有内置与自定义角色都能在家长设置中独立保存音色配置。
- 首页操作与后续来电页的心智一致，统一使用“邀请来电”。
- 角色加载、失败、数据警告和参考音频失效都有明确且符合受众的处理。
- 360 × 640、390 × 844、412 × 915 以及 130% 文字缩放下不出现关键内容裁切。

## 2. 已比较方案

### 方案 A：完整分层并持久化角色音色（采用）

儿童首页与家长设置完全分离，新增独立音色偏好存储，适用于内置和自定义角色。结构最符合已批准的产品设计，后续新增角色也无需在首页增加技术表单。

### 方案 B：仅新增家长设置，首页仍保留部分音色入口

开发量较小，但儿童和成人边界仍然含混，同一配置会出现两个入口，因此不采用。

### 方案 C：只调整首页视觉

不改变数据和导航，无法解决卡片过高、文案与来电流程不一致及内置角色无法持久化配置的问题，因此不采用。

## 3. 信息架构

```text
儿童首页
├── 家长设置入口
├── 角色卡片 → 邀请来电 → 角色来电页
├── 加载占位
└── 加载失败 → 重新加载

家长设置
├── 角色切换（所有内置与自定义角色）
├── 当前音色摘要
├── 预置音色／音色设计／音色克隆
├── 保存音色
└── 角色管理
    ├── 新建角色
    └── 自定义角色：编辑／删除
```

## 4. 儿童首页

页面标题使用“今天想邀请谁给你打电话？”，辅助文案使用“选一位伙伴，稍后他会打给你”。右上角提供带图标和文字的“家长设置”按钮，触控区不小于 48 × 48。

角色卡整卡可点击，包含 88～96px 头像、单行角色名、最多两行介绍和“邀请来电”提示。卡片不显示音色选择、输入框、文件上传、新建、编辑或删除操作。角色主题色只用于浅色背景、描边和操作提示，正文保持足够对比度。

整个页面使用可滚动布局，使标题和卡片在小屏与大字体下自然滚动。点击卡片时读取该角色已保存的音色；未保存时使用角色默认预置音色。准备参考音频期间卡片显示局部忙碌状态，防止重复邀请。

## 5. 家长设置

家长设置采用明亮界面，通过顶部角色选择器切换所有角色。主体展示当前角色头像、名称、当前音色摘要以及现有 `VoiceSelector` 的三种模式。保存按钮执行校验并将结果写入本机，成功后显示“音色设置已保存”；失败时保留编辑内容并显示可重试提示。

角色管理位于音色区域之后：始终提供“新建角色”；仅自定义角色提供“编辑角色”和“删除角色”。删除继续使用确认对话框，并同时清理该角色的音色偏好和本地参考音频。内置角色不可编辑或删除。

自定义角色编辑器只负责基本信息、角色设定和开场白。新角色先使用首个可用预置音色作为安全默认值，创建后可在家长设置中继续配置音色，避免出现两个相互冲突的音色入口。

## 6. 数据与组件边界

### `CharacterPage`

负责儿童首页状态、导航和邀请流程。它不持有可编辑音色表单，只从角色目录状态读取角色的有效音色。

### `CharacterCard`

改为无业务状态的展示组件，输入角色、忙碌状态和邀请回调。角色名与介绍设置行数和溢出规则，并提供明确的语义标签。

### `ParentSettingsPage`

负责角色切换、音色表单、保存反馈及自定义角色管理。角色切换后重建音色表单，初始值来自该角色的有效音色。

### `CharacterVoicePreferencesRepository`

以 schema version 1 的 JSON 文件保存 `characterId → VoiceSelection`，覆盖内置与自定义角色。音色克隆文件导入应用私有 `voices/` 目录，JSON 仅保存相对路径；加载时恢复绝对路径。写入采用临时文件加重命名，失败时不覆盖旧配置，并清理被替换或删除的参考音频。

### `CharacterCatalogController`

合并角色目录、音色选项与音色偏好，提供以下行为：

- `voiceFor(Character)`：返回已保存偏好，否则返回角色默认音色。
- `saveVoice(characterId, selection)`：持久化并更新当前状态。
- 删除自定义角色时同步删除对应偏好。
- 对不存在角色的陈旧偏好进行清理或忽略。

角色本体与音色偏好保持分离，避免修改只读的内置角色资产，也避免自定义角色编辑与家长音色设置互相覆盖。

## 7. 异常与降级

- 角色目录加载中：显示两张与最终布局一致的静态骨架卡，减少布局跳动。
- 角色目录加载失败：显示儿童友好文案“伙伴们暂时没有出现”，提供“重新加载”。
- 本地自定义角色数据损坏：儿童首页继续展示可用角色；详细警告只在家长设置显示。
- 已保存的克隆音频不存在：邀请时静默回退到角色默认预置音色；家长设置显示“参考音频需要重新选择”。
- 保存失败：不退出页面、不清空输入，使用 Snackbar 告知重试。
- 删除失败：保留角色和偏好，显示错误 Snackbar。
- 没有可用角色：显示空状态并引导家长前往新建角色。

## 8. 视觉与无障碍

- 沿用品牌蓝 `#4E72E6`、页面背景 `#F6F7FB`、主文字 `#252A3A` 和角色主题色。
- 标题 28px、粗字重；正文 16px；辅助文字不小于 13px。
- 卡片圆角 24px、轻柔阴影、内容间距使用 8px 倍数。
- 所有普通触控目标至少 48 × 48；邀请卡整体可点击。
- 角色名单行省略，介绍最多两行省略。
- 为卡片、家长设置、重试、编辑和删除提供中文 Semantics 标签。
- 状态不只依赖颜色，忙碌、错误和保存成功均同时使用文字或图标。

## 9. 测试范围

- Repository：内置角色偏好保存/读取、三种音色序列化、克隆文件导入、替换与删除清理、损坏记录降级。
- Controller：默认音色回退、保存后状态更新、自定义角色删除时偏好清理、偏好存储失败时状态保持。
- 儿童首页：不出现音色技术文案和角色管理；所有角色显示并可邀请；家长设置导航；加载、失败、空状态与重试。
- 家长设置：切换所有角色、加载已保存音色、校验与保存、新建/编辑/删除只在正确角色出现、警告展示。
- 自定义角色编辑器：不再展示音色表单，创建时写入安全默认预置音色。
- 回归：来电与通话页收到正确的有效音色；现有通话、音频和服务端测试继续通过。
