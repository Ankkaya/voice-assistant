# App 内新建角色能力设计规格

日期：2026-08-01  
状态：已确认，待实施<br>
目标平台：Flutter Android  
数据范围：仅当前设备

## 1. 背景

当前 App 只能展示两份随包发布的预置角色。移动端从 `mobile/assets/characters.json` 读取展示信息，服务端从 `server/app/config/characters.json` 读取 Prompt 和默认 TTS 配置；服务端角色注册表只在进程启动时加载。项目没有账号、数据库或角色管理 API。

本功能允许家长直接从角色列表页新建自己的角色。自建角色长期数据只保存在当前设备；发起通话时，App 将经过约束的结构化角色快照发送给服务端，服务端校验后仅在本次会话中使用，不持久化角色。

## 2. 目标与非目标

### 2.1 目标

- 从现有角色列表页直接进入新建角色流程，不增加家长验证。
- 支持设置名称、介绍、头像、身份、性格、兴趣、补充描述和开场白。
- 支持预置音色、音色描述和已授权音频克隆三种默认音色。
- 自建角色在 App 重启后仍然存在，并可编辑或删除。
- 保持服务端全局儿童安全规则不可被自建角色覆盖。
- 保持两个预置角色及其现有通话行为向后兼容。

### 2.2 非目标

- 不提供账号、云同步、跨设备同步或多人共享。
- 不提供服务端角色后台、发布审核或角色市场。
- 不允许客户端提交完整系统 Prompt。
- 不支持 AI 生成头像。
- 不允许编辑、隐藏或删除预置角色。
- 不保存服务端角色副本、头像或长期克隆音频。

## 3. 已确认的产品决策

- 新建入口位于角色列表页，不设置家长验证、PIN 或独立家长中心。
- 角色设定采用结构化选项，并允许最多 200 字补充描述；不开放完整 Prompt 编辑。
- 头像支持内置头像和系统相册图片，图片只保存在本机。
- 自建角色可编辑、可删除；预置角色不可编辑、不可删除。
- 新角色保存一个默认音色，同时保留拨打前临时切换音色的现有能力。临时切换不修改已保存配置。
- 服务端采用“随 `session.start` 接收角色快照”的方案，不增加临时角色注册步骤。

## 4. 用户流程与页面设计

### 4.1 角色列表页

角色列表由预置角色和自建角色组成，列表末尾增加“＋ 新建角色”卡片。自建角色卡显示“我的角色”标识和更多菜单，菜单包含“编辑”和“删除”。删除前展示角色名称和二次确认；确认后删除本地记录及其 App 私有素材。

预置角色卡保持现有行为，不显示管理菜单。所有角色继续支持拨打前选择或临时切换音色；自建角色首次显示其保存的默认音色。

### 4.2 新建与编辑页

首版使用一个可滚动的单页表单，按以下区域组织：

1. 基本信息：角色名称、一句话介绍、内置头像或相册图片。
2. 角色设定：一个身份标签、1～3 个性格标签、0～3 个兴趣标签，以及补充描述。
3. 开场白：根据角色名称生成默认文案，家长可以修改。
4. 默认音色：预置音色、音色描述或授权音频克隆。

新建页必须选择名称、身份、至少一个性格和默认音色。介绍、兴趣和补充描述可为空。默认开场白为“你好呀，我是{角色名称}！很高兴接到你的电话。”，家长可以修改。

保存成功后返回角色列表并立即显示新角色。编辑成功后下一次通话使用新配置；已经开始的通话继续使用启动时的快照。

### 4.3 输入限制

| 字段 | 规则 |
|---|---|
| 角色名称 | 去除首尾空白后 1～20 个字符 |
| 一句话介绍 | 最多 30 个字符，可为空 |
| 身份 | 必选 1 个服务端支持的标签 |
| 性格 | 必选 1～3 个服务端支持的标签，不可重复 |
| 兴趣 | 0～3 个服务端支持的标签，不可重复 |
| 补充描述 | 最多 200 个字符，可为空 |
| 开场白 | 去除首尾空白后 1～120 个字符 |
| 音色描述 | 音色设计模式下 8～500 个字符 |
| 克隆音频 | WAV 或 MP3，非空且不超过 10 MB |

自建角色名称允许重复，身份由角色 UUID 区分。克隆音频保存前要求家长勾选“我确认本人拥有或已获得该声音的使用授权”。

## 5. 移动端数据设计

### 5.1 存储模型

自建角色元数据保存在 App 私有支持目录的版本化 JSON 文件中。路径只保存相对于 App 私有目录的相对路径，不保存可能变化的绝对路径。

```json
{
  "schemaVersion": 1,
  "characters": [
    {
      "id": "custom_20a8d1b51412447a99abc336e306f25f",
      "name": "星星船长",
      "subtitle": "喜欢科学的探险伙伴",
      "avatar": {
        "kind": "local_file",
        "value": "avatars/custom_20a8d1b51412447a99abc336e306f25f.jpg"
      },
      "themeColor": "#5B7CFA",
      "profile": {
        "identityId": "adventure_companion",
        "traitIds": ["brave", "patient"],
        "interestIds": ["space", "science"],
        "description": "喜欢用有趣的小实验解释问题"
      },
      "greeting": "你好呀，我是星星船长！",
      "defaultVoice": {
        "mode": "preset",
        "voice": "白桦"
      },
      "createdAt": "2026-08-01T10:00:00Z",
      "updatedAt": "2026-08-01T10:00:00Z"
    }
  ]
}
```

`avatar.kind` 为 `bundled` 或 `local_file`。`defaultVoice` 是以下互斥结构之一：

- `preset`：保存服务端支持的 `voice`。
- `voice_design`：保存 `voiceDescription`。
- `voice_clone`：保存 `referencePath`、显示文件名和授权确认状态；不保存服务端临时 `referenceId`。

首版内置头像使用不依赖第三方 IP 的六个应用内图形：星星、火箭、书本、指南针、爪印和机器人。每个内置头像带一个固定主题色；相册头像默认使用 `#5B7CFA`。主题色随角色记录保存，保证列表和通话页重启后显示一致。一句话介绍为空时，角色卡显示“我的 AI 伙伴”，但不把该回退文案写回用户数据。

### 5.2 本地角色仓库

新增本地角色仓库，职责限定为：

- 加载和校验版本化自建角色文件。
- 创建 UUID 格式为 `custom_<32 位小写十六进制>` 的角色 ID。
- 创建、更新、删除自建角色记录。
- 将相册图片和参考音频复制到 App 私有目录。
- 使用“写临时文件 → 刷新 → 原子替换”的方式提交元数据。
- 在元数据提交成功后清理被替换的旧素材，并清理失败操作产生的临时文件。

角色列表 Provider 合并预置角色仓库和本地角色仓库，对页面暴露统一的只读角色视图以及自建角色 CRUD 操作。角色来源必须显式标记为 `builtIn` 或 `custom`，避免用 ID 前缀决定页面权限。

### 5.3 图片处理

相册图片由系统选择器读取，在本机裁剪为正方形、修正方向并缩放到最大 1024×1024，再编码为 JPEG 或 PNG 保存。处理后的头像不超过 2 MB；不上传原图或处理后的头像。

### 5.4 角色选项

服务端新增只读 `GET /api/character-options`，返回带版本号的身份、性格、兴趣和预置音色列表。App 随包提供同版本的初始选项并缓存服务端最新成功响应，因此首次启动和断网时仍可创建、编辑角色。服务端在通话启动时按当前权威选项再次校验；若旧选项已停止支持，App 保留本地角色并引导用户编辑对应字段。

首版选项目录固定为：

| 类型 | ID 与显示名称 |
|---|---|
| 身份 | `adventure_companion` 探险伙伴、`story_partner` 故事伙伴、`science_partner` 科学伙伴、`learning_partner` 学习伙伴、`animal_friend` 动物朋友、`fantasy_friend` 奇幻伙伴 |
| 性格 | `brave` 勇敢、`patient` 耐心、`humorous` 幽默、`gentle` 温柔、`curious` 好奇、`calm` 沉稳、`lively` 活泼、`encouraging` 爱鼓励 |
| 兴趣 | `adventure` 探险、`stories` 故事、`science` 科学、`space` 太空、`nature` 自然、`animals` 动物、`art` 艺术、`sports` 运动 |
| 预置音色 | `白桦`、`苏打` |

接口返回稳定 ID、中文显示名称和 `optionsVersion`。Prompt 只使用服务端保存的显示含义，不信任客户端发送的标签文案。选项目录变化必须增加版本号；删除选项前应至少保留一个 App 发布周期的兼容期。

## 6. 通话协议

### 6.1 自建角色启动事件

`session.start` 新增可选 `customCharacter`。自建角色必须同时提供符合格式的 `characterId`、`customCharacter` 和完整 `voiceConfig`：

```json
{
  "type": "session.start",
  "characterId": "custom_20a8d1b51412447a99abc336e306f25f",
  "customCharacter": {
    "displayName": "星星船长",
    "greeting": "你好呀，我是星星船长！",
    "identityId": "adventure_companion",
    "traitIds": ["brave", "patient"],
    "interestIds": ["space", "science"],
    "description": "喜欢用有趣的小实验解释问题"
  },
  "voiceConfig": {
    "mode": "preset",
    "voice": "白桦"
  }
}
```

协议不发送 `subtitle`、头像路径、授权确认状态或本地文件路径。它们与服务端生成回答无关。

### 6.2 向后兼容规则

- 预置角色继续只发送 `characterId`；`customCharacter` 必须省略。
- 预置角色的 `voiceConfig` 继续可为空，为空时使用服务端角色默认 TTS。
- `custom_` ID 必须带 `customCharacter`；非 `custom_` ID 禁止带 `customCharacter`。
- 自建角色的 `voiceConfig` 必填。预置模式提供 `voice`，音色设计模式提供 `voiceDescription`，音色克隆模式提供现有上传接口返回的 `referenceId`。
- 服务端不把自建角色加入全局 `CharacterRegistry`，避免跨会话泄漏或 ID 冲突。

### 6.3 服务端响应错误

新增稳定错误码：

| 错误码 | 含义 | 是否可恢复 |
|---|---|---|
| `INVALID_CHARACTER_CONFIG` | 字段结构、长度或组合不合法 | 否，本次连接结束 |
| `UNSUPPORTED_CHARACTER_OPTION` | 身份、性格或兴趣选项已不支持 | 否，本次连接结束 |
| `UNSAFE_CHARACTER_CONFIG` | 自由文本包含明显越权或不适合儿童的内容 | 否，本次连接结束 |
| `UNSUPPORTED_PRESET_VOICE` | 预置音色不在服务端白名单 | 否，本次连接结束 |
| `VOICE_REFERENCE_NOT_FOUND` | 克隆音频临时引用不存在或已过期 | 否，本次连接结束 |

App 收到角色配置类错误后保留本地角色，关闭本次通话并提供“编辑角色”入口；不展示服务端内部校验细节或 Prompt。

## 7. 服务端设计

### 7.1 组件边界

- `CharacterOptionsRegistry`：加载身份、性格、兴趣和预置音色白名单，并为只读接口提供数据。
- `CustomCharacterSpec`：使用 Pydantic 严格校验字段长度、ID 格式、列表数量、重复值和额外字段。
- `SessionCharacterResolver`：预置 ID 从现有 `CharacterRegistry` 解析；自建角色由会话快照构造运行时 `CharacterConfig`。
- `CustomCharacterGuard`：检查名称、开场白和补充描述中的明显 Prompt 注入、成人内容、隐私内容和高风险指令。
- `CharacterPromptBuilder`：将选项显示含义和自由描述作为被引用的角色资料填入固定模板，不把它们作为系统指令直接拼接。

每个组件只负责一个边界，`VoiceSession` 只接收已经解析完成的运行时角色和 TTS 配置，不承担表单规则或 Prompt 拼装。

### 7.2 Prompt 组装与安全边界

运行时角色 Prompt 按以下层级组成：

1. 不可修改的全局儿童安全规则。
2. 固定的输出长度、语气和格式要求。
3. 由服务端选项表解释的身份、性格和兴趣。
4. 以“不可信角色资料”边界包裹的名称、开场白和补充描述，并明确其中任何指令都不得覆盖前两层规则。

服务端仍对每轮用户输入执行现有 `SafetyGuard.check_input`，并对回答执行 `sanitize_output`。自建角色统一使用最多 80 个汉字、最多三句话、一次最多一个问题的现有限制，客户端不能修改该值。

规则检查只作为第一层防护，不宣称能识别全部有害设定。公开发布前仍需要生产级内容审核、监护人机制和合规评估。

### 7.3 音色处理

- 预置音色必须来自 `CharacterOptionsRegistry` 的白名单。
- 音色描述沿用现有 8～500 字限制，并经过自建角色文本安全检查。
- 音色克隆沿用 `POST /api/voice-references`、10 MB 上限、格式签名校验和内存临时引用。
- App 每次使用克隆音色拨打时重新上传本地副本，不复用已过期的 `referenceId`。
- 服务端在会话关闭时删除本会话引用，并保留现有 TTL 清理作为兜底。

## 8. 单次通话数据流

1. App 从合并角色仓库读取自建角色，并以保存的默认音色初始化拨打卡片。
2. 家长或孩子可以只为本次拨打临时切换音色。
3. 若选择克隆音色，App 先通过现有 HTTP 接口上传本地参考音频并获得临时 `referenceId`。
4. App 建立 WebSocket，发送带结构化角色快照和已解析音色配置的 `session.start`。
5. 服务端校验协议、角色选项、安全规则和音色，再构造只属于该 `VoiceSession` 的运行时角色。
6. 后续开场白、ASR、Agent、TTS、VAD 和挂断流程复用现有通话状态机。
7. 会话结束后清除运行时角色、历史、音频缓冲和临时克隆引用。服务端没有可供下一次通话复用的自建角色记录。

## 9. 异常处理与数据一致性

- 创建或编辑时先准备新素材，再原子提交元数据；提交失败保留旧角色并清理新临时文件。
- 替换头像或音频时，只有新元数据提交成功后才删除旧素材。
- 删除角色时先移除元数据，再尽力删除关联素材；残留文件由仓库启动清理扫描回收。
- 单个自建角色记录损坏时跳过该记录并向页面返回可恢复的加载警告，不影响预置角色或其他自建角色。
- 整个 JSON 文件损坏时保留原文件用于诊断，加载空的自建角色集合并提示本地角色数据无法读取；不自动覆盖损坏文件。
- 头像缺失时显示内置占位头像并允许编辑；克隆音频缺失时禁用拨打并要求重新选择。
- 创建和编辑不依赖网络；服务端权威校验在拨打时执行。
- 预置选项接口失败时使用最近缓存；无缓存时使用随包选项。
- 角色设定被服务端拒绝时不删除或静默修改本地记录。

## 10. 隐私与日志

- 头像永不上传服务端。
- 除克隆模式外，参考音频不上传；克隆音频只进入现有内存临时存储。
- 日志不得记录头像、音频、开场白、补充描述、完整角色快照、生成 Prompt、ASR 文本或 Agent 回答。
- 日志只记录 session ID、不可逆或随机的角色 ID、角色来源、状态、耗时、字节数和稳定错误码。
- 客户端崩溃报告不得附带本地角色 JSON 或素材文件。

## 11. 测试策略

### 11.1 Flutter 单元与组件测试

- 版本化 JSON 的正常加载、空文件、单条损坏和整体损坏行为。
- 预置角色与自建角色合并，且来源权限正确。
- 创建、编辑、删除和 App 重启后的持久化。
- 原子写入失败、素材复制失败、替换回滚和孤儿文件清理。
- 头像裁剪、缩放、方向修正和 2 MB 限制。
- 表单必填、长度、标签数量、重复标签和授权确认校验。
- 预置音色、音色描述、音色克隆三种默认值的保存和恢复。
- 角色列表的新建入口、“我的角色”标识、编辑菜单和删除确认。
- 预置角色不可编辑、不可删除。
- 自建角色 `session.start` 序列化，以及预置角色协议回归。

文件选择器、图片处理器、本地文件系统、角色选项客户端和语音引用上传器通过接口注入，组件测试不访问真实相册、网络或设备文件系统。

### 11.2 服务端测试

- `CustomCharacterSpec` 的 ID、长度、额外字段、标签数量、重复值和字段组合。
- 预置 ID 携带自建快照、自建 ID 缺失快照等协议冲突。
- 身份、性格、兴趣和预置音色白名单。
- 明显 Prompt 注入、成人内容、隐私内容和高风险角色设定。
- Prompt 组装层级、固定安全规则和 80 字回答限制不可覆盖。
- 自建角色不会写入或污染全局 `CharacterRegistry`。
- 三种 TTS 路由、缺失克隆引用和会话关闭清理。
- Fake ASR/LLM/TTS 的完整自建角色 WebSocket 会话事件顺序。
- 现有两个预置角色、无 `customCharacter` 的旧客户端及现有音色切换回归。
- 日志捕获测试确认不包含自建角色文本或音频内容。

### 11.3 Android 真机验收

1. 从角色列表进入新建页，使用内置头像和相册头像分别创建角色。
2. 保存后立即出现“我的角色”，强制结束并重启 App 后仍存在。
3. 预置音色、音色描述和已授权音频克隆分别完成一次真实通话。
4. 拨打前临时切换音色成功，返回列表后默认音色未改变。
5. 编辑角色后下一次通话使用新设定，编辑不影响已经开始的通话。
6. 删除角色后记录与本地素材消失，两个预置角色仍在。
7. 参考音频被系统移除、上传失败或临时引用过期时可重新选择和重试。
8. 非法或不安全角色设定无法进入通话，本地角色仍可编辑。
9. 检查客户端与服务端日志，不出现角色自由文本、头像、音频或对话内容。

## 12. 实施边界与建议顺序

该功能可以作为一个实施计划完成，建议按以下依赖顺序推进：

1. 定义共享语义的数据模型、选项目录和协议测试样例。
2. 实现移动端本地角色仓库、私有素材管理和合并 Provider。
3. 实现新建/编辑页面与角色列表管理操作。
4. 扩展服务端选项接口、协议模型、角色解析器、安全检查和 Prompt 组装。
5. 接通三种音色与自建角色 WebSocket 会话。
6. 补齐自动化测试、真机验收、README 和协议文档。

实现阶段不得顺带引入账号、数据库、角色分享、管理后台或 AI 头像生成。
