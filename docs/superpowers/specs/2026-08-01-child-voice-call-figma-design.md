# 儿童 AI 角色电话 Figma 设计规格

日期：2026-08-01  
状态：已完成方案讨论，待书面复核  
目标平台：Flutter Android  
设计基准：390 × 844，兼容 360 × 640 与 412 × 915  
素材范围：当前角色图片仅用于内部设计原型，不得用于公开分发

## 1. 背景

当前项目是面向 6～9 岁儿童的 AI 角色语音电话应用。Flutter 客户端包含角色选择、角色来电、半双工语音通话、本地 VAD、三种 MiMo 音色模式以及参考音频上传；FastAPI 服务端负责 ASR、角色 Agent、TTS 和会话安全。

现有实现同时混合了儿童通话体验与内部音色实验能力：角色卡直接展示预置音色、音色设计和音色克隆选项；用户点击“给角色打电话”后，下一页却显示角色来电。新设计需要保留现有能力，同时重新整理信息架构，使儿童主流程简单、连贯、可理解。

## 2. 产品定位

产品定位为儿童正式体验，成人可以独立配置角色音色。

- 儿童主流程只包含角色选择、角色来电和语音通话。
- 首页右上角提供清晰的“家长设置”入口。
- 家长设置点击后直接打开，不使用 PIN、系统身份验证或算术题。
- 三种音色能力全部保留在家长设置中：预置音色、音色设计、音色克隆。
- 每个角色的音色配置独立保存在本机，后续邀请来电自动使用。
- 当前两张第三方角色图片继续用于内部 Figma 原型，但必须在 Cover 和资产说明中标注不可公开分发。

## 3. 设计目标

1. 让儿童无需理解技术概念即可邀请角色来电并完成通话。
2. 让“儿童操作”和“成人配置”在信息架构上完全分离。
3. 保留真实电话的沉浸感，同时使用适合儿童的文案、图形和触控尺寸。
4. 让连接、聆听、说话、思考、角色回答和错误状态容易区分。
5. 建立可复用的 Figma 变量、样式和组件，能够映射现有 Flutter 界面。
6. 在小屏、较大字体和最长状态文案下避免内容裁切、重叠或溢出。

## 4. 非目标

- 账号、登录、数据库、历史记录或长期记忆。
- 底部导航、聊天文字记录、联系人管理或社交功能。
- iOS 专项页面和 iOS 组件适配。
- 插话打断、全双工通话或断线续聊。
- 公开发行所需的版权授权、家长同意与儿童隐私合规全套页面。
- 改变现有 ASR、Agent、TTS、WebSocket 或 VAD 技术架构。

## 5. 信息架构

```text
角色选择
├── 角色卡片
│   └── 邀请角色来电
└── 家长设置
    ├── 角色切换
    ├── 预置音色
    ├── 音色设计
    └── 音色克隆

邀请角色来电
└── 角色来电
    ├── 拒绝 → 角色选择
    └── 接听
        ├── 麦克风权限
        ├── 正在连接
        ├── 角色说话
        ├── 聆听
        ├── 孩子说话
        ├── 角色思考
        ├── 可恢复错误
        └── 挂断／结束 → 角色选择
```

## 6. 核心体验

### 6.1 角色选择

角色选择使用温暖故事绘本风格：明亮背景、大圆角卡片、宽松留白、粗字重标题和角色主题色。页面标题为“今天想邀请谁给你打电话？”，辅助文案为“选一位伙伴，稍后他会打给你”。

角色卡整卡可点击，包含：

- 角色头像
- 角色名称
- 一句话介绍
- “邀请来电”操作提示

角色卡不显示音色模式、输入框、文件上传或技术术语。右上角显示“家长设置”。

### 6.2 角色来电

来电与通话采用沉浸式真实电话风格：深色模糊角色背景、大头像、明显的接听绿和拒绝红。来电页显示角色名称、“AI 角色来电”和“正在呼叫你…”。

拒绝后立即停止铃声并返回角色选择；接听后停止铃声，首次使用时申请麦克风权限，然后进入连接状态。

### 6.3 通话中

通话页面只保留挂断按钮。页面使用固定纵向安全区：

1. 顶部信息区：通话类型与计时。
2. 头像视觉区：角色头像与状态光环。
3. 身份／状态区：角色名、主状态、通话时长、麦克风状态。
4. 底部操作区：挂断按钮。

角色名限制一行并在超长时省略；主状态最多两行；麦克风状态保持单行；挂断按钮固定在底部安全区，不随文字高度移动。高度不足时依次缩小头像、光环和区间间距，不缩小触控区域。

状态光环和文案：

| 状态 | 主文案 | 麦克风提示 | 视觉反馈 |
|---|---|---|---|
| `connecting` | 正在连接 | 麦克风已暂停 | 中性脉冲 |
| `assistantSpeaking` | {角色名}正在说话 | 麦克风已暂停 | 暖色声波光环 |
| `listening` | 你可以说话啦 | 麦克风正在聆听 | 蓝色呼吸光环 |
| `userSpeaking` | 我在听 | 麦克风正在聆听 | 更明显的蓝色声波 |
| `processing` | {角色名}正在想一想 | 麦克风已暂停 | 紫色柔和脉冲 |
| `error` | 儿童可理解的错误文案 | 依据恢复状态 | 红色提示光环 |
| `ended` | 通话已结束 | 不显示 | 动效停止 |

### 6.4 家长设置

家长设置沿用明亮界面，不进入深色电话模式。页面包含角色切换与当前音色摘要，并为三种模式提供分段选择器。

预置音色：

- 显示可选音色列表、当前选中状态和试听入口。
- 保存后更新对应角色的本机配置。

音色设计：

- 显示声音描述输入框、示例、字数限制和保存状态。
- 保留现有至少 8 个字、最多 500 字的约束。

音色克隆：

- 持续显示“仅使用本人或已明确授权的声音”。
- 支持 WAV／MP3，文件不超过 10 MB。
- 展示空状态、已选文件、上传中、上传失败和需要重新选择音频。
- 参考文件或服务端引用不可用时，通话安全回退至该角色默认预置音色；儿童界面不显示技术错误，家长设置显示需要处理的提示。

## 7. 页面与状态范围

### 儿童界面

- 角色选择：正常、加载中、加载失败。
- 角色来电：响铃、接听、拒绝。
- 接听过渡：麦克风权限、正在连接。
- 通话中：角色说话、聆听、孩子说话、角色思考、可恢复错误。
- 结束：主动挂断、通话超时、角色告别、不可恢复错误。

### 家长设置

- 角色切换与当前音色摘要。
- 预置音色列表、试听和保存。
- 音色设计输入、校验、保存中、保存成功、保存失败。
- 音色克隆空状态、文件已选、上传中、上传失败、引用失效。

### 系统级场景

- 首次麦克风权限。
- 权限被拒后的成人协助提示。
- 无网络或服务不可用。

轻微状态通过组件变体表达，不为每个状态复制整套屏幕。

## 8. 视觉与设计令牌

### 8.1 色彩

| 语义 | 当前基准值 |
|---|---|
| 品牌蓝 | `#4E72E6` |
| 温暖强调色 | `#F5B83C` |
| 页面背景 | `#F6F7FB` |
| 主文字 | `#252A3A` |
| 次文字 | `#777C8D` |
| 卡片背景 | `#FFFFFF` |
| 默认边框 | `#D8DAE2` |
| 接听／成功 | `#31B768` |
| 挂断／错误 | `#E84545` |
| 拉布拉多角色色 | `#E7A93B` |
| 莱德角色色 | `#E64B4B` |

语义色变量提供 `Child Light` 与 `Call Dark` 两种场景模式。角色主题色独立为角色令牌，不硬编码进通用组件。

### 8.2 字体

中文使用 Noto Sans SC。基础文字样式：

- Display：32px。
- 页面标题：28px。
- 区块标题：22px。
- 组件标题：18px。
- 正文：16px。
- 辅助文字：13px。

儿童界面使用较粗字重和宽松行高。数字计时使用等宽数字特性。

### 8.3 间距与尺寸

- 基础间距：4、8、12、16、20、24、32、40。
- 圆角：8、12、16、24、Full。
- 普通触控区域：至少 48 × 48。
- 接听、拒绝、挂断按钮：72～76px。
- 角色头像：标准通话头像 176px，小屏最小 148px。

### 8.4 效果

- 卡片使用轻柔阴影，不使用高对比厚重投影。
- 通话背景使用角色图片放大模糊、深色遮罩和可读性渐变。
- 状态光环使用颜色、透明度和节奏表达，不改变整体布局尺寸。

## 10. 数据与交互规则

- 家长音色配置按角色保存在本机，不跨账号或设备同步。
- 儿童邀请来电时，客户端自动读取该角色已保存的音色配置。
- 角色来电页负责响铃、接听和拒绝；接听后才连接服务端。
- 通话保持现有半双工模型；AI 播放时麦克风暂停，播放结束后恢复聆听。
- 任意状态均允许挂断；挂断立即停止铃声、录音、播放和连接。
- 减少动态效果开启时，呼吸和声波动画替换为静态光环与图标变化。

## 11. 异常处理

- 角色加载失败：插画式空状态和“重新加载”。
- 麦克风权限被拒：提示“请找大人帮忙打开麦克风”，提供返回首页。
- 连接失败：提示“角色现在打不进来”，允许重新邀请。
- 未听清：提示“我刚刚没有听清，可以再说一次吗？”，随后恢复聆听。
- 可恢复模型错误：使用短文案，自动恢复聆听。
- 不可恢复错误：停止音频资源，展示结束状态并返回角色选择。
- 界面不展示供应商名称、协议、状态码、堆栈或其他技术术语。

## 12. 无障碍

- 重要文字与背景满足 WCAG AA 对比度。
- 状态同时使用文案、图标和视觉反馈，不只依赖颜色。
- 支持减少动态效果。
- 关键触控目标至少 48 × 48，电话操作按钮至少 72 × 72。
- 支持 130% 文字缩放；小屏和放大文字下不能遮挡头像、状态或挂断按钮。
- 所有按钮具有明确的中文语义标签。

## 14. 验收标准

Figma 交付必须验证：

1. 360 × 640、390 × 844、412 × 915 三种 Android 尺寸。
2. 默认文字与 130% 文字缩放。
3. 两个角色及角色主题色切换。
4. 角色选择、来电、连接、说话、聆听、思考、错误和结束状态。
5. 三种家长音色模式及文件上传状态。
6. 最长角色名、最长错误文案和长文件名。
7. 头像下方信息、底部挂断按钮、输入框和上传组件无裁切、重叠或溢出。
8. 所有流程屏使用设计系统变量和组件实例，不保留无意的硬编码样式。
9. 当前角色素材明确标注“仅限内部原型，不可公开分发”。

## 15. 与当前实现的主要差异

- 将音色选择从每张儿童角色卡迁移到独立家长设置。
- 将首页操作文案从“给角色打电话”改为“邀请来电”，与来电页一致。
- 为每个角色增加本机音色配置持久化语义。
- 将现有通话界面规范为固定安全区，明确文字行数和小屏适配顺序。
- 补齐加载失败、权限拒绝、连接失败、音色引用失效和通话结束设计。

这些差异属于设计方案范围；本轮交付目标是 Figma 文件，不直接修改 Flutter 或服务端代码。
